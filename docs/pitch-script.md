# StakeSensei — 1-minute pitch script

**0:00-0:12**

Crypto beginners watch videos about validator consensus, but the concepts don't stick.

> 暗号資産初心者はバリデーターの仕組みを動画で見ますが、内容が頭に残りません。

**0:12-0:28**

StakeSensei turns that video into a hands-on sandbox. You stake, get picked as leader, and produce a block.

> StakeSenseiはその動画を実際に触れるサンドボックスに変えます。ステークし、リーダーに選ばれ、ブロックを作ります。

**0:28-0:42**

One click toggles to Ethereum mode, showing the same steps as slots, epochs, and attestations.

> ワンクリックでイーサリアムモードに切り替わり、同じ流れをスロットやエポック、アテステーションとして見せます。

**0:42-0:55**

We use real Solana and Ethereum data, so the simulation feels grounded, not just a cartoon.

> 実際のSolanaとEthereumのデータを使うので、シミュレーションは単なるアニメーションではなくリアルに感じられます。

**0:55-1:00**

StakeSensei: learn validators by doing, not just watching.

> StakeSensei:見るだけでなく、実際に操作してバリデーターを学ぼう。
